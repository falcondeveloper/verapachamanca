BUG FOUND
The queue buttons called YouTube IFrame API loadPlaylist().
loadPlaylist() starts playback immediately.

FIX
The buttons now use cuePlaylist(ids, 0, 0).
cuePlaylist loads/cues the first video and waits for the user to press the native
YouTube Play button.
